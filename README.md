# SHFW 3.1.2 / Ninebot G30D 3-Cap: OTA reverse engineering

**Status:** Working passive OTA capture, validated encrypted transfer, independently verified Ninebot TEA decryption, ARM Cortex-M3 application recovered. **No original SHFW C source has been recovered.**

> Research archive, not a firmware distribution, flashing toolkit, or official ScooterHacking project. The repository name `shfw312source` is the user's project name; the exact installed firmware version has **not** been independently proven from a version string in the recovered binary.

## What's here

- `tools/`: Original research tools for RX-only capture, IAP extraction, TEA validation and offline firmware inspection.
- `arduino/`: ESP32-C3 passive UART monitor sketch.
- `ghidra/`: Reproducible starting-point annotation script for the decrypted APP.
- `docs/`: protocol, interpretation, provenance, Ghidra workflow and safety notes.
- `reports/`: non-payload verification metadata and observed counts.

## Quick start: using your local dumps

1. Install Python 3.10+ and `py -3 -m pip install -r requirements.txt`.
2. Capture with `py -3 tools/capture_raw.py --port COM3 --out yellowwire_raw.bin` **only when needed**. No write traffic is generated by this script.
3. Extract with `py -3 tools/extract_iap.py --raw yellowwire_raw.bin --outdir extracted`.
4. Verify/decrypt with `py -3 tools/ninebot_tea_verify.py extracted/session_01_wire_candidate.bin --out local_shfw_app.bin`.
5. Inspect with `py -3 tools/inspect_app.py local_shfw_app.bin --base 0x08001000`.
6. Import the plaintext binary into Ghidra at `0x08001000` (ARM/Thumb little-endian). See `docs/GHIDRA.md`.

**Do not flash the decrypted app as-is.** It contains no proven bootloader or full flash layout. No read-unprotect, mass erase, or option-byte changes are part of this project.
